# Бункер v1.13 - reference canvas

Главный desktop-экран перенесён на фиксированный холст 1536x1024 по утверждённому PNG-референсу.

## Что изменено

- оригинальный референс используется как точная визуальная основа игрового экрана;
- поверх него расположены живые React-слои с реальными данными комнаты;
- свои характеристики всегда видны владельцу;
- чужие характеристики по-прежнему раскрываются по правилам игры;
- кандидаты, ход, раунд, голосование, карта условия, катастрофа и журнал остаются интерактивными;
- весь desktop-холст масштабируется целиком, поэтому пропорции референса не расползаются;
- мобильный интерфейс пока не переделан под этот новый референс - это отдельный этап после утверждения desktop.

## Техническая схема

`public/reference-v113.png` - визуальный эталон 1536x1024.
`app/page.tsx` - интерактивные области и живые данные поверх эталона.
`app/globals.css` - фиксированные координаты и масштабирование холста.

Полная сборка Next.js в текущей среде не выполнялась из-за отсутствующих локально пакетов Next/React/@types/node; синтаксических ошибок TypeScript при разборе изменённого JSX не обнаружено до ошибок отсутствующих зависимостей.
